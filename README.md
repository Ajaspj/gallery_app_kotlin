# 📸 Smart Gallery

A modern Android gallery application built with **Kotlin and Jetpack Compose**, designed to provide a fast, intelligent, and privacy-focused photo browsing experience.

The app uses Android's native media APIs and **on-device Machine Learning** to automatically analyze and organize photos into meaningful categories — without uploading personal photos to a server.

---

## ✨ Features

### 🖼️ Smart Gallery

- Browse real photos from the device gallery
- Modern Material 3 interface
- Responsive photo grid
- Recently added photos
- Dynamic photo categories
- Efficient thumbnail loading
- Smooth scrolling
- Supports images and videos

### 🤖 On-Device Machine Learning

The gallery uses local ML processing to intelligently analyze photos.

Supported analysis includes:

- 👤 Face detection
- 👥 People grouping
- 🐕 Pet detection
- 🐈 Animal detection
- 🌄 Nature detection
- 🍔 Food detection
- 🚗 Vehicle detection
- 📄 Document detection
- 📱 Screenshot detection
- 📝 Text/OCR analysis where supported

ML processing happens locally on the Android device.

> 🔒 Your photos stay on your device.

---

## 🔎 Smart Search

Search can find photos using:

- File names

- ML labels
